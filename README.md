# SketchSearch

给用 Sketch 做设计的人：不必先想起图在哪个文件里，直接搜画板名、页面名或文件名，右侧立刻显示画板缩略图，确认后一键用 Sketch 打开。

应用在本地为 `.sketch` 文件建立索引，自己解析 Sketch 的 zip 结构与 JSON，不依赖 Python 或第三方库。索引只读源文件；只有开启 Spotlight 同步时，才会往文件写入关键词属性。

**[下载最新版本](https://github.com/fangdc/sketch-search-app/releases/latest)** · macOS 14 或更高 · Intel / Apple 芯片通用

---

## 功能

| 能力 | 说明 |
| --- | --- |
| 即时搜索 | 输入画板名、页面名或文件名，结果实时更新；多个关键词用空格分隔，需要全部命中 |
| 三种结果 | 工具栏切换「画板 / 页面 / 文件」，结果按文件修改时间排序，最近改过的在前 |
| 画板预览 | 选中画板后调用 Sketch 自带的 `sketchtool` 精确导出该画板，右侧显示缩略图 |
| 高清拷贝 | 「拷贝预览图」把画板按 3x 导出 PNG 到剪贴板，超大画板长边封顶 6000px |
| 矢量拷贝 | 「拷贝矢量画板」按 Sketch 原生剪贴板格式复制，粘到 Sketch 里是可编辑图层 |
| 打开与定位 | 「在 Sketch 中打开」「在 Finder 中显示」「复制路径」 |
| 单文件浏览 | 右键结果选「查看该文件全部画板」，只看这个文件里的画板，可返回搜索结果 |
| 全局唤起 | 默认 ⌥Space，在任何应用里叫出搜索窗口 |
| 菜单栏常驻 | 关窗收进菜单栏，后台自动刷新继续；菜单里显示索引规模与上次刷新时间 |
| 自动刷新 | 默认每 10 分钟增量更新；切回应用且距上次超过 2 分钟也会更新 |
| Spotlight 同步 | 把画板名、页面名写入文件关键词，⌘空格 也能搜到对应 `.sketch` 文件 |
| 快捷键自定义 | 唤起、刷新、打开三个快捷键都能重录，也可恢复默认 |

### 安全设计

- 只索引你亲手选过的文件夹，首次启动不预置任何目录。
- 索引阶段对 `.sketch` 只读；不修改、不移动、不删除文件。
- Spotlight 同步只写入关键词扩展属性；可在设置里点「清除已写入的关键词」全部撤销。
- 不联网、不上传、没有统计上报。
- 缩略图缓存上限 200 MB，超出后按最久未使用淘汰。

## 系统要求

- macOS 14 或更高，Intel 和 Apple 芯片都可以。
- 无需安装其他组件；缩略图预览依赖已安装的 Sketch（未安装时搜索仍可用）。

## 安装

1. 从 [Releases](https://github.com/fangdc/sketch-search-app/releases/latest) 下载 `SketchSearch-1.0.1.dmg`，打开后把 **SketchSearch.app** 拖到「应用程序」。
2. 没有 Apple 开发者证书签名，首次打开会被拦；用下面任意一种方式放行（只需一次）：
   - **方式一（终端）**：`xattr -dr com.apple.quarantine /Applications/SketchSearch.app`
   - **方式二（不用终端）**：双击 →「无法打开」→「完成」→ 系统设置 → 隐私与安全性 → 仍要打开。
3. 首次运行按提示选择存放 `.sketch` 的文件夹。

---

## 第一次使用

1. 启动后出现「欢迎使用 SketchSearch」，点「选择文件夹」，选中存放 Sketch 文件的目录，可一次选多个。
2. 点「开始使用」，应用开始建立索引。
3. 在搜索框输入画板名、页面名或文件名；右侧预览确认后，按 ⌘↩ 用 Sketch 打开。

通过这个窗口选中的文件夹会自动获得系统授权。以后要增删目录，去「设置 → 索引目录」。

## 搜索与筛选

搜索会在画板名、页面名和文件名里同时匹配，命中部分高亮显示。输入多个关键词时用空格分隔，结果需要同时命中所有关键词。

工具栏的三个筛选页签分别对应画板、页面和文件：

- **画板**：每条结果是一个具体画板，右侧显示它的缩略图，可拷贝预览图或矢量数据。
- **页面**：按页面名匹配。页面本身没有缩略图，选中后可右键「查看该文件全部画板」逐个预览。
- **文件**：按 `.sketch` 文件名匹配，选中后右侧显示这个文件的封面图。

结果按文件修改时间倒序排列，最近改过的文件排在前面。右键一条结果可以「在 Sketch 中打开」「在 Finder 中显示」「复制文件路径」，或进入这个文件的画板列表单独浏览。

## 预览与拷贝

选中画板后，应用调用 Sketch 自带的 `sketchtool` 按画板 id 精确导出，而不是截取整页。首次打开大文件需要加载整个文档，可能要几秒；导出结果按文件修改时间和画板缓存，再次选中是瞬时的。

预览区可以：

- **缩放与平移**：用右上角的 + / − / 恢复按钮，或在触控板上捏合缩放、拖动平移。
- **拷贝预览图**：按 3x 重新导出高清 PNG 到剪贴板，可直接粘进 Figma、Keynote 或聊天窗口。
- **拷贝矢量画板**：按 Sketch 原生剪贴板格式复制画板图层，粘到另一个 Sketch 文件里仍是可编辑的图层，不是图片。

「拷贝预览图」和「拷贝矢量画板」只对画板结果有意义，所以只在「画板」筛选下显示。

## 索引与自动刷新

索引是增量的：用文件的修改时间和大小判断是否需要重新解析，没变化的文件直接跳过。文件被删除或移出索引目录后，对应记录也会移除。

自动刷新默认开启，每 10 分钟检查一次，可在「设置 → 索引目录」改为 5 分钟到 3 小时；每次切回应用时，如果距上次刷新超过 2 分钟，也会自动更新一次。扫描会跳过 `node_modules`、`.git`、`.Trash`、`Library/Caches`、`sketch-assets` 这些目录。

## 同步到聚焦搜索

开启「把画板名 / 页面名同步到 Spotlight 关键词」后（默认开启），应用会把每个文件的画板名和页面名写进文件的 Spotlight 关键词属性，并调用系统 `mdimport` 刷新索引。之后在 ⌘空格 里直接搜画板名，就能找到对应的 `.sketch` 文件。

设置页可以手动「立即同步」或「清除已写入的关键词」，并显示已标注文件数。系统对单文件关键词容量有上限，应用会按 18 KB / 900 条主动封顶，超出的部分只能在应用内搜到。

## 它对你的电脑做了什么

- 只读取你选中的索引文件夹里的 `.sketch` 文件；不修改、不移动、不删除。
- 开启 Spotlight 同步时，会写入 `com.apple.metadata:kMDItemKeywords` 扩展属性，并调用 `mdimport` 刷新系统索引。
- 不联网、不上传、没有统计上报。
- 数据放在：

  ```
  ~/Library/Application Support/SketchSearch/
  ├── index.db           索引数据库（SQLite）
  ├── thumbs/            画板缩略图缓存（上限 200 MB）
  └── sketchsearch.log   运行日志
  ```

- 拷贝预览图会在系统临时目录生成一次性文件，完成后删除；异常退出留下的残留会在下次启动清理。
- **彻底卸载**：退出应用，删掉 `/Applications/SketchSearch.app`，再删掉 `~/Library/Application Support/SketchSearch/`；如果不再需要写入 Sketch 文件的 Spotlight 关键词，先在「设置 → 聚焦搜索」点「清除已写入的关键词」。要连偏好设置一起清掉，可执行 `defaults delete com.sksearch.app`。

## 已知限制

- **不能直接跳到某个画板**：Sketch 没有提供「打开文件并定位到指定画板」的接口，只能打开文件后手动点一下。
- **Spotlight 关键词有容量上限**：单文件超过约 18 KB / 900 条会被系统截断，超出部分只能在应用内搜到；设置页会显示被截断的文件数。
- **Sketch 重新保存文件可能丢掉关键词属性**，需要等自动刷新补回来（应用会自动处理）。
- **未安装 Sketch 时无法生成缩略图**，但搜索、筛选、复制路径和拷贝矢量画板仍可用。
- **首次打开需要手动放行**：应用使用临时签名，没有经过 Apple 公证，按「安装」里的方式放行一次即可。
